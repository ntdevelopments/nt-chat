# NT Chat

**Modern Customisable Chat | Qbox · QBCore** · by [NT Development](https://ntdevs.com)

> This repository is a showcase. The resource itself is delivered through Tebex / Cfx.re Asset Escrow after purchase.

![NT Chat](https://dunb17ur4ymx4.cloudfront.net/packages/images/f338eb84375913b7652af0478df20d491f6cfc72.jpeg)

Replaces the default chat. Every script using `chat:addMessage` keeps working without changes.

## Preview
[![Preview video](https://img.youtube.com/vi/AMkXOYlxUlQ/maxresdefault.jpg)](https://www.youtube.com/watch?v=AMkXOYlxUlQ)

## Features
- /me, /do, /try, /looc, /ooc, /pm, staff chat, announcements, reports
- /me, /do, /try above the head as a bubble or plain text
- Settings panel for every player; the owner can lock settings
- Emoji picker, TAB autocomplete, channels, spam protection
- Languages: English, Turkish
